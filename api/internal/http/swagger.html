Explore device settings, heartbeats, and motion events.

Download OpenAPI

1. Authorize requests

Click Authorize below and enter your API_TOKEN without Bearer. Local Compose uses dev-token unless changed in .env. No account or password is needed.

2. Choose a device

Use the ESP32 factory MAC address as device_id. To simulate a device, send a heartbeat with the example MAC, then list devices. An empty list means no devices have contacted the API.

3. Execute a request

Expand an operation, fill its parameters, then click Execute. A 401 means the token is missing or incorrect. Health checks are public. Requests use the current host.
